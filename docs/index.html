两页现在的关系与边界
  1. 入口互通且带参数：账本页顶栏「方案卡 →」与每条策略的「按这个方案点 →」会把当前区间、策略类型一并带过去；原型左上角「← 账本」可跳回。
  2. 同一份数据、同一份引擎：决策页内嵌账本的事实表与 range.mjs，页内可切 7 天 / 30 天 / 90 天 / 全部，常点商品、券、价格即时重算——与账本页切区间用的是同一段代码。
  3. 色彩口径统一在 tokens.css（唯一口径），决策页构建时内联同一份变量；账本页为单文件自包含，按同值内联。
  4. 下单仍是模拟：价格按菜单现价估算（原型不联网），真实下单前必须重新结算；支付在麦当劳自有 H5 收银台完成，本工具不收集支付信息，也不代付。
